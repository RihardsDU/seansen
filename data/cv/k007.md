# Ingrid Gravstø

**Rolle:** Skyarkitekt · **Lokasjon:** Oslo

Ingrid er skyarkitekt med ti års erfaring, de siste seks med Azure og infrastruktur som kode. Hun har bygget landingssoner i Terraform for to store kunder i energi og bank, og liker å lære opp team i moduler og gode pipelines.

**Nøkkelkompetanse:** Terraform, Azure, AKS, Azure DevOps, GitHub Actions
**Utvalgte oppdrag:** Nordlys Kraft (plattformarkitekt, 2025–2026), Bølgen Bank (DevOps-lead, 2023–2024)
